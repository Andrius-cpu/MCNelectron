# MCNelectron

MCNelectron is an open-source Monte Carlo code designed to simulate the transport and interaction of high-energy electrons and photons in matter. Distributed under the GNU General Public License (GPL), the complete software package includes all executables, comprehensive documentation, and the full source code for both MCNelectron and MCNScript.The distribution is packaged as a WinRAR self-extracting archive.

**Key Components Included**
1. **Dual Processing Engine Options**
   
   **Standard CPU Version:** Optimized for single or multi-core central processing units.

   **CUDA-Enabled Version (MCNelectron_CUDA):** Utilizes NVIDIA GPUs to run high-performance "hybrid" computations, splitting simulation workloads across the CPU and GPU in parallel for maximum acceleration.
3. **MCNScript (Front End)**

    An open-source GUI and workflow coordinator built to simplify simulation management and graphical rendering. Features include:
   
     Interactive dialog interface for editing command-line arguments and organizing input/output files.
   
     Controls for calculating particle-track statistics and track filtering.
   
     Automated generation of raytracing visualization scripts.
   
   **Note on Graphics Visualization:** Raytracing scripts generated by MCNScript are fully compatible with **MGED** (Multi-Device Geometry Editor, part of the open-source **BRL-CAD** suite). MGED processes these scripts to render precise wireframe or raytraced 3D images using Constructive Solid Geometry (CSG) techniques.
